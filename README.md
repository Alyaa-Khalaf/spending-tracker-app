# 💸 Spending Tracker

تطبيق ويب لتتبع المصاريف الشهرية وإدارة الميزانية  
A web app to track monthly expenses and manage your budget

## ✨ المميزات / Features

- 🌙☀️ Dark / Light mode
- 🌐 Arabic / English support (RTL + LTR)
- 📊 Donut chart for spending by category
- 📈 Budget progress bars with warnings
- 🗂 Filter by All / Week / Month
- 💾 Auto-save to localStorage
- ➕ Add & delete transactions
